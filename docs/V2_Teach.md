# PullerView V2 — 教示画像の保存（2.0.7.0／タグ `V2-v8`）

作成: 2026-11-27

## 1. 内容

オペレータが「この画像は実際は NG／OK」と印を付けた画像を、通常の受信画像（`[Image]`。最新 `max_files` 枚で自動削除）とは別のフォルダへ残す。
教示は誰でも行える（パスワードなし。2026-11-20 決定）。

**この版は保存だけを行う。** 教示画像を再解析して設定値（閾値・検出範囲など）を自動提案する機能、判定履歴の過去の画像を選んで教示する機能、設定画面の項目は未実装。

## 2. 操作

PullerView のウィンドウを右クリック → 「教示: この画像は実際は NG（時刻 工程）」または「…実際は OK」。

- 対象は**メニューを開いた時点で表示していた最新の画像**（メニュー項目に撮影時刻と工程を表示）。
- 結果はイベントログに出る。保存できなかったとき（上限・書込み失敗）はメッセージも出る。
- 晶線解析が無効、`[Teach] enable=0`、アイコン表示中、画像を 1 枚も受信していないときはメニューに出ない。

## 3. 保存先と記録

フォルダ: `VisionView.ini [Teach] folder`（既定 `NgTeach`。相対は EXE 基準）。

- 画像: `YYYYMMDDHHMMSS_工程_TEACH-NG.bmp`／`…_TEACH-OK.bmp`（日時は教示した時刻。受信したままの BMP）。
- 記録: `teach.csv`（UTF-8 BOM、1 教示 1 行）。

| 列 | 内容 |
|---|---|
| teach_time, label, file | 教示日時、教示内容（NG／OK）、保存したファイル名 |
| image_time, source_name | 画像の時刻、元のファイル名 |
| process | 工程（NECK〜TAIL。対象外は NA） |
| judge, frame_status, detected | そのときの判定（OK／NG／WAIT／OFF）、その 1 枚の扱い、晶線を検出したか |
| confidence_pct, hit, count | 真偽度と、その内訳（検出回数／測定回数） |
| contour, judge_mode, seam_threshold, seam_threshold_strong, detect_range | そのときの検出方式・判定方式・閾値・検出範囲 |
| seam_deg, seam_d, comment | 検出した晶線の角度と特徴量、画面のコメント |

## 4. 上限

| 設定 | 既定 | 内容 |
|---|---|---|
| `max_files` | 200 | 教示画像の上限枚数（0=無制限）。フルサイズ 1 枚約 15 MB なら 200 枚で約 3 GB、1/2 サイズ約 3.7 MB なら約 0.75 GB |
| `on_full` | `stop` | `stop`=上限に達したら保存しない（古い画像を残す）／`delete_oldest`=古い画像から削除して保存。`teach.csv` の行は削除しない |

既定を `stop` にした理由: 教示画像は NG 判定の根拠なので、気付かないうちに消えるより、保存できないことを知らせる方が安全なため。

## 5. 確認したこと／していないこと

- サンドボックス（Mono）で保存処理を単体確認: 保存した BMP が元データと一致、記録の内容、上限での `stop`／`delete_oldest`、無効時・画像なし、ini の読み書き。
- **未確認**: 右クリックメニューからの操作と画面表示（コンパイルのみ）、Windows 実機、VS2022 でのビルド。
- メモリ: 教示用に最新 1 枚分の BMP（フルサイズで約 15 MB）を保持する。
