# PullerView V2 — ZR アドレス指定によるグラフ項目の選択（2.0.4.0／タグ `V2-v5`）

作成: 2026-11-26

## 1. 目的

グラフ（上下限監視）の PV / SV を、従来のデータリスト index（0〜149。`stcMCValue` の配列位置）に加えて、
`stcRealData.intIOBit` に含まれる **ZR アドレス（ZR110000〜ZR112299）** でも指定できるようにする。
PullerView は読取り専用のまま（VB_FERROTEC / PLC へは書き込まない）。

## 2. 根拠（12 インチ FT-CZ3212 の VB_FERROTEC ソース）

`mdlPcObjRWPLC.sub_Update_RealTimeData`:

```
num = 110000; num2 = 112299;
array = mdlPLC.fnc_Plc_Get_D("ZR", num, num2 - num + 1);   // 2,300 ワード
stcRealData.intIOBit = array;
```

- `intIOBit[i]` = ZR(110000 + i)。実機（8・12 インチ）で確認済みの配列長 2300 と一致する。
- 以前調査したソース（`docs/analysis_vbferrotec_source.md` S-7）は 2,100 ワード（〜ZR112099）だった。版による違い。
  配列が 2,100 ワードの装置では ZR112100 以降は値なし（`---`）になる。

## 3. 指定方法

| 指定値 | 意味 | 復号 |
|---|---|---|
| 0〜149 | データリスト index n | `intIOBit[200+2n]`（下位）・`[200+2n+1]`（上位）÷ McMeta.ini の除数。一部は 2 項目の合計（従来どおり） |
| 110000〜112299 | ZR アドレス a | `intIOBit[a-110000]` から ZrMap.ini の `words`（1=16bit／2=32bit 下位・上位の順）で取り出し、`div` で割る |

- `DataSetting.ini` の `pv_pcinfodata_index` / `sv_pcinfodata_index` に 110000 以上を書くと ZR アドレスになる（キー名は互換のため変えていない）。
- 設定画面: index 欄に ZR アドレスを直接入力するか、「一覧から選ぶ」で選ぶ。一覧は検索欄と種別（すべて／index／ZR／ZR 名称ありのみ）で絞り込める。
- ZR アドレス指定では「2 項目の合計」（index 17+101 など）は行わない。合計値が必要な項目は index で指定する。

## 4. ZrMap.ini（EXE と同じフォルダ）

`ZR110200.xlsx`（12 インチのアドレス割り付け表。`docs/reference/ZR110200_FT-CZ3212.xlsx`）から生成。1,025 項目（1,500 ワード分）。

- 表にあるアドレス: ZR110200〜111199、ZR111500〜111699、ZR112000〜112299。
- 表にないアドレス（ZR110000〜110199、ZR111200〜111499、ZR111700〜111999）も指定はできる（1 ワード・除数 1・名称なし）。
- ワード数の決め方: 偶数アドレスで次のアドレスが同名（下位／上位）または空欄なら 2 ワード。ZR110800〜111199（プロファイル領域）は表のとおり 1 ワードずつ。
- 「XX:XX:XX に変換」の項目は秒の生値のまま（単位 s、除数 1）。

### 除数（div）の信頼度 — 重要

| div_src | 件数 | 内容 |
|---|---|---|
| `mcmeta` | 137 | ZR110200〜110499 のうち McMeta.ini（装置から受信）に名称のある項目。除数・単位・3 言語名は McMeta.ini の値 |
| `table` | 274 | 割り付け表の書式（`XXX.X mm` → 除数 10）からの**推定。未確認** |
| `none` | 614 | 表に書式なし。除数 1 は**仮** |

ZR110200〜110499 で表の書式と装置の除数を比べると、比較できた 130 項目中 **27 項目が不一致**だった
（例: 籽晶高速速度 表 `XXX.XX`=100／装置 1000、晶棒重量 表 100／装置 10）。
したがって `table` / `none` の除数は、使う項目ごとに実機の表示値と照合する必要がある。違っていれば ZrMap.ini の `div` / `words` / `signed` を直す。

照合には診断モードが使える（値・生値・除数・ワード数を毎秒表示）:

```
PullerView.exe --headless 30 65,110504,111002
```

## 5. 確認したこと／していないこと

- サンドボックス（Mono）で復号を単体確認: index65 と ZR110330 が同値、2 ワード（ZR110504, ZR112294）、1 ワード・符号付き（ZR110801）、表にないアドレス、範囲外（ZR109999, ZR112300 → 値なし）、2,100 ワード配列での ZR112294（値なし）。
- `DataSetting.ini` に ZR アドレスを書いた設定の読込（範囲外は警告して無効化）。
- **未確認**: 実機の Remoting 経由での値、一覧ダイアログの画面表示（コンパイルのみ）、VS2022 でのビルド、`table` / `none` の除数。
- CSV ログ（`PV_yyyyMMdd.csv`）の列は従来どおり McMeta.ini の項目のみ。ZR アドレスで指定した項目は CSV に出力しない（未対応）。

## 6. ZrMap.ini の更新（2.0.5.0／タグ `V2-v6`、2026-11-26）

開発責任者が編集した ZrMap.ini を `config/ZrMap.ini` にそのまま反映した（プログラムの変更はバージョン番号のみ）。

- 項目数は 1,025 のまま（追加・削除なし）。ワード数・符号の変更なし。
- 変更: 除数 24 項目、単位 22 項目、名称（caption）7 項目、3 言語名の追加 13〜14 項目、`div_src` 8 項目（none → table）。
- 更新後の `div_src` の内訳: mcmeta 137／table 282／none 606（4 章の表は V2-v5 時点の件数）。
- **注意**: `div_src=mcmeta` のまま、除数が McMeta.ini（装置から受信した値）と異なる項目が 14 ある:
  ZR110342, 110344, 110388, 110390, 110400, 110404, 110412, 110414, 110416, 110418, 110424, 110442, 110464, 110488
  （ZR110388, 110390, 110412, 110416 は単位も変更。ほかに ZR110488 は除数と単位、ZR110466, 110480, 110484 は単位のみ McMeta.ini と異なる）。
  これらは index 指定（McMeta.ini の除数）と ZR アドレス指定（ZrMap.ini の除数）で表示値の桁が変わる。
  また一覧では「McMeta」（確認済み）の表示のままになる。どちらの除数が正しいかは実機の表示値との照合が必要。
