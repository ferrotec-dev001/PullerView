# V2-v14（2.0.13.0）晶線の山の選び方と XG-X 画像の受信待ち時間

## 1. 輝度方式（NECK）の追加設定 — VisionView.ini の工程セクション
| キー | 値 | 内容 |
|---|---|---|
| `seam_score` | `abs`（既定）／`sigma` | `sigma`＝特徴量を、その画像の検出範囲内のばらつき σ（中央絶対偏差×1.4826）で割った偏差で評価する。`seam_threshold` は σ の倍数になる（目安 2.5） |
| `peak_select` | `all`（既定）／`top` | `top`＝最大の山が閾値以上のときだけ検出とし、ほかの山は最大の山から晶線間隔（90°など）の整数倍 ± `pair_tol_deg` にあるものだけ残す |
| `partner_ratio` | 0.1〜1.0（既定 0.6） | `top` のとき、相手の山に必要な値＝閾値×この倍率 |

既定値は従来と同じ動作（abs／all）。試すときの例: `seam_score=sigma`、`peak_select=top`、`seam_threshold=2.5`。
座標展開グラフの縦軸も、`sigma` のときは偏差（σ の倍数）になる。

## 2. XG-X 受信フォルダの待ち時間 — [Xgx]
- 既定値を `stable_ms=1000`→`100`、`scan_ms=500`→`50` に変更（`scan_ms` の下限は 20）。INI が旧既定値（1000／500）のままのときは、読み込み時に新しい既定値へ置き換える。
- 待ち時間を短くした代わりに、ファイルの中身（JPEG の終了マーカー FFD9／BMP ヘッダーのファイルサイズ）でも書込み完了を確認する。
- 解析が終わった直後に、受信フォルダをすぐ確認する（次の `scan_ms` を待たない）。
- 解析中に届いた画像は、いちばん新しい 1 枚だけを残し、追い越された画像は解析しない（従来どおり。画像の保存は行う）。

# V2-v15（2.0.14.0）
- 輝度方式の既定値を偏差方式に切替: `seam_score=sigma`、`peak_select=top`、NECK の `seam_threshold=2.5`。
- 設定画面「晶線解析設定」→「工程ごとの検出設定」（検出方式が輝度のとき）に「偏差（σ）で評価」「最大の山と相手のみ」のスイッチと「相手の山の倍率」を追加。「偏差（σ）で評価」を切り替えると検出閾値を目安の値（偏差 2.5／そのまま 1.0）に戻す。
- `seam_score` が無い INI（V2-v14 以前）を読んだとき、輝度方式の工程は偏差方式の既定値（閾値 2.5）に置き換える。
- SHOULDER・TAIL の既定値を BODY と同じにした（ridge／single／閾値 0.2／検出範囲 18–62°・122–160°／hold）。既にある VisionView.ini の [SHOULDER]・[TAIL] の値は変えない。
